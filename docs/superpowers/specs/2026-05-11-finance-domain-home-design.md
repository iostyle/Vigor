# 财经领域个性化主页设计

## 背景

首页右侧仪表盘在未选择视频时展示通用空状态,缺少领域语境。用户希望未选择视频时展示当前领域的个性化页面,先实现财经领域。

## 目标

- 未选择视频时不再展示“请选择一个视频查看详细数据”。
- 财经领域展示有明确金融语境的主页,帮助用户快速进入选题和分析状态。
- 结构预留领域扩展点,后续可按领域增加独立设计。
- 保持 Apple 风格:克制、留白、信息分组清晰,兼容浅色/深色主题和移动端。

## 财经主页信息架构

1. 顶部概览:显示“财经情报台”、领域名称、核心说明和三个关键观察指标。
2. 市场温度:用四个固定维度呈现政策、资本、消费、全球市场的内容热度线索。
3. 机会雷达:列出可优先关注的财经内容方向,强调选题价值和判断标准。
4. 内容策略:给出用户选择视频前可参考的分析动作,把页面从空状态变为工作台。

## 视觉设计

- 主色避免单一蓝紫,采用冷静蓝、盈利绿、风险橙的组合。
- 使用柔和边框、轻量阴影和 8px 以内卡片圆角。
- 图形元素采用 CSS 渲染的折线/坐标网格,避免依赖外部图片。
- 深色主题下降低高饱和色面积,保持文字层级清晰。

## 扩展约定

`DomainHomePage` 根据领域名称选择设计。当前仅财经定制,其他领域展示中性兜底主页,后续逐个补充领域专属模块。
