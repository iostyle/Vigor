# 影视领域个性主页设计

## 背景

当用户进入影视领域但未选择具体视频时,首页需要展示领域级内容入口,不再使用通用空状态。

## 设计目标

- 展示与影视内容相符的榜单式主页,参考烂番茄的扫描体验。
- 当前预设两个数据库驱动模块:国内热门剧集、海外流媒体。
- 院线热映不从视频数据库生成,后续应接入淘票票、猫眼或第三方电影 API 等实时来源。
- 使用当前视频列表动态分组,避免写死会过期的影片或剧集名称。
- 保持 Vigor 现有 Apple 风格:克制留白、清晰层级、浅色/深色主题变量兼容。

## 信息架构

- 顶部概览:影视热榜室、热度指数、国内剧集/海外流媒体/互动概览。
- 国内热门剧集:匹配国产、电视剧、剧集、悬疑、喜剧、古装、短剧等关键词。
- 海外流媒体:匹配韩剧、韩国、K-Drama、Netflix、奈飞、网飞、HBO、Disney、美剧、欧美、好莱坞、海外电影、典型海外影视 IP 等关键词。
- 编辑精选:复用当前领域推荐视频,提供快速进入详情的入口。

## 成功标准

- 影视领域未选择视频时展示影视专属主页。
- 财经领域和通用领域不受影响。
- 榜单项可点击进入视频详情。
- 空分区展示采集提示,不出现空白面板。
- 院线热映暂不展示,避免用视频数据库数据误导当前上映榜单。
- 构建通过。
