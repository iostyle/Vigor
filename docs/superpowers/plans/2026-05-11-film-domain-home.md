# 影视领域个性主页实现计划

## 步骤

1. 识别影视领域。
   - 验证:领域名称包含影视、电影、剧集、电视剧或娱乐时进入影视模板。

2. 增加影视主页模板。
   - 验证:未选择视频时展示顶部热度概览、两个榜单分区和编辑精选。

3. 实现动态分组逻辑。
   - 验证:根据标题、作者、标签关键词归入国内剧集、海外流媒体。

4. 移除数据库驱动的院线热映模块。
   - 验证:院线热映不展示,后续可改由淘票票、猫眼或第三方电影 API 提供实时上映数据。

5. 补充影视专属样式。
   - 验证:布局在桌面端双列展示,移动端单列展示,不影响财经样式。

6. 运行前端验证。
   - 验证:`npx prettier --check src/components/dashboard/DomainHomePage.vue` 和 `npx vite build` 通过。
