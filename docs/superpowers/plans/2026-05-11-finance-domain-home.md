# 财经领域个性化主页实现计划

## 成功标准

- 未选择视频时显示领域主页,不再出现旧空状态文案。
- 当前领域为财经时显示财经专属布局。
- 选择视频后原有视频详情、评论摘要、AI 分析功能不受影响。
- 前端构建通过。

## 任务

1. 接线当前领域
   - 在首页计算当前激活领域。
   - 将领域对象传入数据仪表盘。
   - 验证:类型检查不报错。

2. 新增领域主页组件
   - 创建 `DomainHomePage.vue`。
   - 实现财经专属模块和默认兜底。
   - 验证:未选择视频时可渲染财经页面。

3. 替换通用空状态
   - 在 `DataDashboard.vue` 中用领域主页替代旧提示。
   - 保留视频已选择时的原流程。
   - 验证:旧文案不再存在于界面模板。

4. 构建验证
   - 运行 `npm run build`。
   - 修复类型或样式明显问题。
